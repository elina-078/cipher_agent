# 🕵️ ШПИОН: СЕКРЕТНОЕ ДЕЙСТВИЕ (СПЕЦОПЕРАЦИЯ: ШИФР)

Мобильная веб-игра для смартфонов, объединяющая тактильную атмосферу секретных спецслужб (агентурная сеть, засекреченные досье, шифробуквы, условные сигналы) и современную мобильную эргономику. Готова к публикации на **GitHub Pages**!

---

## 🌟 Ключевые возможности и изменения

1. **Главная тема: Спецслужбы и Секретные Агенты (Intelligence & Agents):**
   - 🛡️ **Штаб агентурной сети:** стильный тактический интерфейс в тонах глубокого карбона (`#0a0d14`), оружейной стали, изумрудных индикаторов (`#22c55e`) и золотых элементов грифа секретности (`#f59e0b`).
   - 🂠 **Новый дизайн рубашки карты:** гербовый тактический щит, 8-конечная Роза Ветров (Intelligence Star), круговой визир-радар, микросетка безопасности, грифы `СОВЕРШЕННО СЕКРЕТНО`, `ГРИФ: ОВ` и штрихкод авторизации.
   - 📁 **Досье оперативника:** при открытии карты мирный агент связи видит свою шифробукву и условный сигнал; вражеский шпион видит статус шпиона без буквы и действия.

2. **Свободный выбор количества шпионов (любое число):**
   - Прямо на карточке настроек встроены интерактивные кнопки-степперы `[ − ]` и `[ + ]`.
   - Нажатие на число или иконку карандаша `✏️` открывает модальное окно с прямым вводом любого числа и быстрыми пресетами.
   - Ограничено только базовым правилом игры: должно оставаться хотя бы 3 мирных агента для составления слова (`шпионов <= игроков - 3`).

3. **Чистый кольцевой таймер:**
   - Убраны лишние значки под таймером.
   - Одно касание по кольцу таймера плавно ставит раунд на паузу или возобновляет отсчёт с понятным статусом.
   - Убрана лишняя кнопка «Подсказать вопрос» для максимальной чистоты и концентрации игроков.

4. **Прямой переход без лишних экранов:**
   - Убрана раздражающая модалка «Первым задаёт вопрос».
   - После того как все игроки изучили свои досье, игра сразу начинает совещание и запускает таймер.

5. **База данных и правила:**
   - 📚 **111 182 русских слова встроено:** словарь существительных от 3 до 14 букв загружен непосредственно в игру (никаких загрузок и интернета).
   - 🎭 **194 незаметных условных сигнала:** большая база жестов, доступных для каждого раунда (действия не исключаются из списка возможных).
   - ⚙️ **Настройка победы шпиона:** переключатель «Победа шпиона при расшифровке» (ВКЛ / ВЫКЛ).

## 🚀 Публикация на GitHub Pages

1. Создайте публичный репозиторий на [GitHub](https://github.com/new).
2. Загрузите файлы:
   - `index.html`
   - `style.css`
   - `app.js`
   - `words.js`
   - `actions.js`
3. В настройках репозитория откройте **Settings** ➔ **Pages** ➔ выберите ветку `main` (или `master`) / root ➔ нажмите **Save**.
4. Через 1 минуту игра доступна по ссылке на любом смартфоне!
